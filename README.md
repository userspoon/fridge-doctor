# ❄️ Холодильник Доктор — ассистент диагностики холодильников

Чат-бот-экспертная система: ведёт диагностику неисправностей бытовых холодильников
по уточняющим вопросам и выдаёт ранжированный список вероятных причин с проверками,
устранением и оценкой сложности работ.

Инструмент рассчитан на специалиста: формулировки нейтрально-технические,
без «обратитесь к мастеру».

## Как запустить

**Вариант 1 (проще всего):** дважды кликните `index.html` — файл полностью
автономен (HTML + CSS + JS в одном файле), интернет не нужен, работает в любом
браузере, в том числе на телефоне.

**Вариант 2 (локальный сервер):**

```bash
cd fridge-doctor
python -m http.server 8791
# открыть http://127.0.0.1:8791
```

## Что умеет

- **8 сценариев диагностики:** не морозит, не включается, щёлкает, шумит,
  вода/протекает, лёд и «шуба», перемораживает/не отключается, запах.
- **Уточняющие вопросы с ветвлением** — с учётом типа системы
  (No Frost / капельная) и особенностей двухкомпрессорных моделей.
- **Карточки причин:** вероятность, признаки, пошаговая проверка, устранение
  и **уровень сложности работ** — 🔧 Простая / 🔧🔧 Средняя / ⚙️ Спецоборудование
  (вскрытие контура, станция, заправка).
- **Свободный ввод:** «течёт вода», «щёлкает и не запускается» — бот сам
  распознает симптом по ключевым словам (список слов редактируется).
- **Опрос при старте:** модель (по шильдику), возраст и число компрессоров
  (по шильдику: одна доза хладагента — один компрессор, две — два) —
  автоматически попадают в карточку диагностики.
- **📚 Мануалы**: бот сам читает файлы (PDF с текстовым слоем, DOCX, XLSX, DOC, TXT или вставка текста) — извлечение прямо в браузере, хранение на устройстве (IndexedDB), мгновенный поиск по всей библиотеке с фрагментами.
- **🤖 ИИ (Ollama)**: подключение к локальной Ollama (http://localhost:11434, нужен запуск с OLLAMA_ORIGINS=*), выбор модели, ответы на вопросы мастера по загруженным мануалам с указанием источников.
- **🔢 Справочник кодов ошибок** по брендам: Indesit/Ariston (обе
  платформы), Атлант (No Frost и двухкомпрессорные), Samsung, LG,
  Liebherr, Bosch/Siemens/Neff, Beko, Whirlpool, Gorenje, Haier,
  Electrolux, Vestel, Vestfrost, Hansa, Ardo, Daewoo — с поиском по
  коду, слову и бренду. Код можно написать прямо в чат («ошибка F5») —
  бот покажет расшифровку по всем брендам.
- **Карточка диагностики:** сводка сессии ответов с версиями и кнопкой
  «Скопировать» — для заявки, журнала или переписки.
- **Справочник** (узлы, быстрые проверки) и **техника безопасности**
  (включая горючий хладагент R600a).

## 🎓 Обучение — редактор базы знаний

Кнопка «🎓 Обучение» открывает редактор. Всё, что вы добавите или измените,
немедленно применяется в диалоге и сохраняется в этом браузере автоматически.

| Вкладка       | Что можно делать                                                              |
|---------------|--------------------------------------------------------------------------------|
| **Причины**   | Добавлять, править, удалять причины: название, сложность, признаки, проверки, устранение, предупреждение. Есть поиск. |
| **Сценарии**  | Создавать сценарии симптомов: название, иконка, ключевые слова, дерево вопросов (узлы и варианты ответа с целями: следующий узел / результат / переход / ветвление по типу системы). |
| **Результаты**| Итоги диагностики: заголовок, пояснение и упорядоченный список причин с приоритетами и комментариями. |
| **Данные**    | Экспорт базы в JSON-файл, импорт (перенос на другой компьютер / обмен с коллегами), сброс к заводской. |

Прямо из карточки причины в диалоге есть кнопка «✏️ Дополнить в редакторе» —
открывает форму правки этой причины.

### Типовой путь добавления своего сценария

1. **Сценарии → + Новый сценарий** → название, иконка, ключевые слова.
2. В узлах прописать вопросы и варианты; целями вариантов выбрать
   существующие или новые **результаты**.
3. **Результаты → + Новый результат** → добавить причины (свои или из базы)
   с приоритетами «Очень вероятно / Вероятно / Возможно».

## Как устроено внутри

Всё в `index.html`. Заводская база — объект `BUILTIN` (причины `causes`,
сценарии `flows`, результаты `results`). При работе бот читает `KB` — копию
заводской базы, дополненную вашими правками (хранится в `localStorage`,
ключ `fridgeDoctorKB_v1`). Сброс к `BUILTIN` — кнопка на вкладке «Данные».

## Идеи развития

- Telegram-бот на той же базе (структура JSON готова к переносу в Python/Node).
- Фото-вход: фото шильдика или испарителя.
- LLM-слой поверх базы для свободной беседы с ограничением гипотез базой.
- История диагностик и статистика по моделям.
